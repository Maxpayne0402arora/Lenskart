Vision Check for Kids — Metrics

Lenskart Product Case Study

SUCCESS METRICS
Primary Metric

North Star Metric

Attended under-18 eye tests attributable to Vision Check that resulted in a prescription change, per month.

Core Conversion Funnel

Stage Definition Type
Entry → Consent Consent completed / entry shown Leading
Consent → Session Start First target rendered / consent granted Leading
Session Start → Valid Completion Completed and not voided / started Leading
REFER → Booked Bookings / REFER results Leading
Booked → Attended Attended / booked Lagging
Attended → Prescription Changed Power change issued / attended Lagging

Strategic Outcomes

Prescription freshness:

Share of under-18 prescriptions on file under 12 months old.

Time to correction:

Median days from session to glasses in child's hands.

P0 Safety Guardrail

False Negatives Trigger

If > 10% of CLEAR children require a power change within 90 days of an in-store test, the feature is immediately pulled.
